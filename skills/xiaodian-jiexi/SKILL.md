# 笑点解析

解析体（资料行 / 此为N层笑点 / 层尾 / 末句喵）只是壳。真东西只有一句：**每层都要说出「谁把哪句原话当成了什么」**。说不出，就是没解析。

## 0 什么时候用 / 不用

用：有人让你解析一条聊天/一句话/一张图/一个段子为什么好笑。

不用：对方只是让你接话、讲笑话、写段子（那是创作，不是解析）；对方情绪不对、只是骂人（先处理情绪）。

## 1 输入怎么给

- **原话**：谁说的 + 原文（能带上下文更好）。
- **引用/回复**：只解析被引用的那一条，对话里别的话一律不解析。
- **图/视频**：用文字描述（图已转写、视频带字幕）。
- **什么都没给**：只解析最近一条；别把整段都解析。

## 2 每层四问（硬标准，缺一问这层不算）

1. **哪句原话**：把目标里那句原文逐字引出来，一字不改。
2. **字面什么意思**：这句话按字面该怎么理解。
3. **实际指什么**：谁把哪个字/词/人名当成了什么，错位在哪（谁把 A 当成 B、哪句话自己打自己的脸）。
4. **机制名**：属于哪种笑（从 `references/术语表.md` 挑一个，一层只用一个机制；同一机制不许拆两层）。

答不出四问：把这一层删掉。一层都答不出：只写 `资料：` 行 + 末句 `令人忍俊不禁喵`，不许凑层凑格式。

## 3 机制对照（摘要；完整 40+ 条见 references/术语表.md）

| 机制 | 一眼判据 | 常见说法 |
|---|---|---|
| 谐音 | 读音像另一个词，意思换掉了 | 司凤≈死冯 |
| 双关 | 同一句话两种读法都成立 | 「随便」=放手 / 不用心 |
| 身份错位 | 该 A 说的话被 B 说了，或同一人被当成两个 | 同名、抢认领 |
| 答非所问 | 回的这句话没接问题，接了别的东西 | 装傻、岔开 |
| 反差 | 前后两句立场/语气打架 | 骂完立刻依赖 |
| 一本正经 | 用最正式的口吻说最离谱的事 | 问责式荒诞因果 |
| 荒诞因果 | 两件无关的事被串成因果链 | 「因为你没过生日，所以……」 |
| 偷换概念 | 主语/前提被悄悄换掉 | 标题把「配音」写成「猫开口」 |
| 分层/三翻四抖 | 同一句被复读/升级，最后一下翻掉 | 越传越歪 |
| 现挂 | 现场的东西当场被拿来做梗 | 字幕和画面当场对不上 |

## 4 输出格式（壳，必须原样）

```
【聊天记录】
昵称：原话
昵称：原话
【解析】
资料：谐音/衍生/字形/出处（查到几样写几样；查不到写「（没查到明确资料）」，绝不许编）
对话中「昵称」说「原话」意思是……，此为1层笑点。
（只有出现新的笑点机制才开下一层）……，此为2层笑点，令人忍俊不禁。
而蠢蠢的ai，回复「它真说过的那句」。没有理解……，令人忍俊不禁喵。
```

硬规则：
- `昵称` 必须换成发那句话的人在本群的称呼；解析自己说过的话就写自己。**出现「代称」「昵称」这两个字本身 = 不合格。**
- 目标文本里括号中的说明（「（他引用的消息）」之类）不是原话，不许写进【聊天记录】。
- `资料：` 这一行必须有；每层必须有 `此为N层笑点` 且从 1 开始连续；除末层外每层结尾接「令人忍俊不禁」；最后一句固定「令人忍俊不禁喵」。
- 【聊天记录】只列【目标】里的原话，逐条原样；目标是图/视频就列 `昵称：［图/视频：…］`。
- 层 = 新的笑点机制；铺垫和揭晓合起来算一层，别一句一层。

## 5 资料怎么查（先索引，再取 1-2 份，别整套塞进来）

1. 判场景：`references/场景对照.md`（S1–S11，按目标类型选档，拿该档推荐术语/说法）。
2. 机制名：`references/术语表.md`（已验/待验分开，待验的只在贴题时用）。
3. 梗式说法：`references/说法表.md`，只夹 1-2 个，每层都夹就成口头禅。
4. 口吻参照：`references/范例.md`（只学怎么指出错位，不抄句式）。
5. 外部资料库：先看 `knowledge/索引.md` —— 喜剧机制卡（MIT，已内置）、幽默大师（无许可，需自取）、Joke Engineering（无许可，需自取）。
6. **情绪参照表（预留）**：`references/情绪参照表.md`。有内容就按它定语气强弱；空就跳过，不要瞎猜。
7. **群友幽默发言学习（预留）**：`references/群友幽默发言学习.md`。命中同类发言/机制就优先照它；空就跳过。

## 6 顺带：用同一套资料优化自己的发言

- 接话先判「该不该接」，再决定一句还是一串；别每条都抖机灵。
- 机制卡只取技巧（铺垫/升级/反转/停顿），不照抄别人的句子。
- 不解释自己的梗（解释笑点 = 杀死笑点）；不报梗名。
- 情绪参照表若有内容，发言前先定语气强弱；群友学习表若有内容，优先沿用同类接法。详见 `references/发言优化.md`。

## 7 自检

```bash
node scripts/check.mjs 答案.md --target "目标原话"
```

没有脚本也要过清单：四问每层都答了？昵称换了？资料行在？层号连续？末句喵？有没有补写目标里没有的表情/动作/心理？

## 8 禁项

- 照格式不解析：只有「意思是／反差在于／正是笑点所在」这类标签，说不出谁把哪句原话当成了什么。
- 占位符：`代称：…`、`昵称：…`。
- 编造：目标里没有的表情、动作、语气、心理、别处对话，一个字都不许补；没查到资料却写出处/平台/时间；编 ai 说过的话。
- 解析到没被选中的对话。

## 9 数据在哪（换台电脑也能找到）

```bash
node scripts/data-locate.mjs --root /path/to/bot
```

只读定位：`data/chat-stars.json`（星标池）、`data/网络热梗.md`（入库梗/群友原话）、`data/xiaodian-history.jsonl`（解析留档）、`data/说话风格.md`、`data/人物喜好.md`。找不到会列候选，手动 `--root` 即可。

星标同一条路：`node scripts/import-stars.mjs --root <bot目录> --dry` 把上面三处数据整理成「群友幽默发言学习.md」的表行（默认只预览不写）。
