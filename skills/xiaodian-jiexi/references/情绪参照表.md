# 情绪参照表（预留 · 尚未填写）

> 状态：**空**。表空时解析/发言都跳过这一节，不许瞎猜语气。

## 这张表解决什么

同一句话语气不同，好笑程度差很多。解析时判断目标那句的情绪强度（轻/中/重）和类型，发言时拿它定自己该用什么语气接。

## 用法

1. 先看目标原话能对上表里哪一行（对不上按「无记录」处理，不硬套）。
2. 对上后：解析语气按「解析语气」列；发言按「接法」列。
3. 一行只对一类情绪，别一表打天下。

## 填写格式（一行一条，用 ｜ 分隔）

```
情绪标签 ｜ 一眼特征（原话里出现什么） ｜ 解析语气（轻/中/重 + 怎么写） ｜ 接法（自己该怎么回） ｜ 例子原话 ｜ 备注
```
