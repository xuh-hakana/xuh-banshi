# 对照样例（不合格 → 合格）

每组：目标原话 / 不合格（照格式不解析）/ 合格（说出谁把什么当成了什么）。

## 样例 1：谐音

**目标**：主人 说「司凤，你死冯了」

**不合格**（有壳没解析）：
```
【聊天记录】
主人：司凤，你死冯了
【解析】
资料：（没查到明确资料）
对话中主人说「司凤，你死冯了」意思是司凤死了，此为1层笑点，令人忍俊不禁。
而蠢蠢的ai，回复「啊？」。没有理解，令人忍俊不禁喵。
```

**合格**：
```
【聊天记录】
主人：司凤，你死冯了
【解析】
资料：谐音/出处（剧名《山河令》角色「司凤」）
对话中主人说「司凤，你死冯了」，字面是「司凤，你死了」，但「死冯」念起来就是「死」，主人把角色名「司凤」的「凤」换成同音的「冯」，等于把名字本身也判了死刑，此为1层笑点。
而蠢蠢的ai，回复「司凤是谁」。没有理解这是在用谐音宣布角色死讯，令人忍俊不禁喵。
```

## 样例 2：身份错位（同名）

**目标**：主人 说「你们俩都叫虚幻，到底谁是」

**合格要点**：指出「同名」被当成了「同一个人」；不能只写「意思是分不清」。

## 样例 3：偷换概念（标题）

**目标**：群友 说「猫开口说话了（其实是配音）」

**合格要点**：指出标题把「配音」偷换成「猫开口」，主体从人换成了猫。

## 常见失败模式

| 症状 | 说明 | 改法 |
|---|---|---|
| 只有「意思是」 | 把原话翻译一遍就算解析 | 补「谁把什么当成了什么」 |
| 「反差在于」空转 | 说了是反差，没说反差的两头是什么 | 把两头原话写出来 |
| 层数灌水 | 一句一层，全是同一个机制 | 一层一个机制，同机制合并 |
| 脑补动作/心理 | 目标里没有的表情、语气 | 删掉，只引原话 |
