# 资料库索引（knowledge/）

先按问题选一份，别整套读进来。

| 想知道什么 | 看哪 | 许可 | 是否随包 |
|---|---|---|---|
| 某个段子用了什么喜剧结构 | `comedy-mechanics/`（68 份 md，含 67 张机制/结构卡） | MIT | 已内置 |
| 机制名的标准叫法 | `../references/术语表.md` | 本包 MIT | 已内置 |
| 什么场景该用什么说法 | `../references/场景对照.md` | 本包 MIT | 已内置 |
| 幽默大师的完整方法论 | `humor-master/` | 未声明 | 需脚本自取 |
| 笑话工程/生成流程 | `joke-engineering/` | 未声明 | 需脚本自取 |

## 自取

```bash
node scripts/fetch-knowledge.mjs            # 两个都拉
node scripts/fetch-knowledge.mjs humor      # 只拉幽默大师
node scripts/fetch-knowledge.mjs joke       # 只拉 Joke Engineering
node scripts/fetch-knowledge.mjs --list     # 只看会拉什么
```

拉取后目录为 `knowledge/humor-master/` 与 `knowledge/joke-engineering/`（已在 .gitignore 里）。

## comedy-mechanics 怎么用

- 文件名是机制/结构名（英文 kebab-case），先列目录再读命中的 1-2 份。
- 每份卡大致是「这是什么 / 怎么用 / 例子」；解析只要第一段和例子，发言只要「怎么用」。
- 不要一次读 10 份：一份卡就够支撑一层笑点的机制名。
