# dsh + AstrBot 人设共用

> 目的只有一个：**解决上下文不够**。
> 人设文件还是你面板里那份，一个字没改；分层是插件在背后做的。

## 唯一来源

```
~/Documents/xuhuan mac/xuhbot/src/soul/虚幻.md
```

- **管理面板**：照原来的方式编辑，格式、结构都不用变
- **QQ 机器人**：照原来的方式读，行为不受影响
- **AstrBot**：插件 `astrbot_plugin_persona_share` 每次调用模型前读它，挑着拼
- **dsh**：`~/.dsh/AGENTS.md` 是指向这份文件的软链接

没有第二份副本，不存在两边不同步。

## 分层规则（插件内部判断，不写在文件里）

| 层 | 内容 | 每轮带不带 |
|---|---|---|
| **人设** | 我是谁 / 性格 / 我、主人、重名的人——身份铁律 | 每轮都带，最高优先级 |
| **说话方式** | 长短 / 不许用括号 / 句号和省略号 / 笑和哭 / 同一句话不说两遍 | 每轮都带 |
| **其余规则** | 我是主人的分身、我身边的人、答游戏攻略、被骂、被围观、接梗…共 17 节 | 按当前消息的关键词挑 2 节，没挑中的只留标题 |

## 实测省多少

| 场景 | 注入字数 | 比全量省 |
|---|---|---|
| 全量（以前） | 6,653 字 | — |
| 普通闲聊「你好啊」 | 2,223 字 | 67% |
| 「你主人叫啥」 | 2,992 字 | 55% |
| 「这机器人好假」 | 2,367 字 | 64% |
| 「这游戏满级多少」 | 2,403 字 | 64% |
| 「笑死我了这个梗」 | 2,738 字 | 59% |

平均省一半以上，且人设和说话方式始终完整。

## 三条兜底（怕漏规则）

1. 某一节**没配触发词** → 当常驻处理，宁可多花 token 也不丢
2. 标题被改过 → 启动时日志会点名警告，不会静默失效
3. 文件读不到 / 编码坏了 → 只记警告，**不影响正常回话**

## 怎么核对

在 AstrBot 里发 `/persona`，会回：

- 全量是多少字、这条消息实际注入多少字、省了百分之几
- 带上了哪几节、哪几节没展开
- dsh 那边接没接

## 开关

AstrBot 后台 → 插件 → 人设共用 → 只有两个设置：

- **总开关**（关掉立刻恢复原样，不改任何东西）
- **人设文件路径**（留空就用上面那份）

没有别的开关。注入方式固定「追加」、按需固定「挑 2 节」——想改就改代码，
加开关只会让行为变得不可预期。

## 插件放在哪

```
~/.astrbot/data/plugins/astrbot_plugin_persona_share/     ← 真身
integrations/dsh-astrbot/插件源码                          ← 指向真身的软链
```

改哪边都是改同一份代码。
