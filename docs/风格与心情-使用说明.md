## 2. DSH：从样例学一套风格（`dsh-writing-style-learner`）

适合：**你贴一段文字，让它学会这套写法，以后每步都按这个写。**

### 2.1 学

在当前窗口直接发（斜杠命令）：

```
/writing-style 学习下面这段的风格，存成档案「虚幻说话」：

<把你的样例粘在这里>
```

或者不用命令，直接说「学一下这个风格」+ 贴样例也行（它会调 `save_writing_style`）。

### 2.2 存哪

`<当前工作区>/Writing-Style/<名字>/profiles.json`

**不是 `~/.dsh`**（以前的桥读错地方了，现在已修，两边都会扫）。

### 2.3 看 / 换

- 问「我现在激活的风格是什么」→ 它会 `show_writing_style`
- 「有哪些风格」→ `list_writing_styles`
- 「换成 XX 那套」→ `activate_writing_style`

### 2.4 什么时候生效

每一步都重新注入系统提示，所以长对话、上下文压缩、新会话都不丢。

## 3. DSH：从改稿学规则（`dsh-style-memory`）

适合：**你先让它写，你手改，它从你的改动里抽规则。** 这个比 2 更贴近「你本人怎么改」。

### 3.1 完整流程

1. 让它写一版草稿
2. 你手改成你满意的版本
3. 两版一起给它：

```
用 style_learn 学一下：
original_text 是 <初稿>，revised_text 是 <我改完的>，
genre 用 chat，note：别每句都收尾总结、少用「其实」。
```

4. 看学成了什么：`/style card`（≤400 字的风格卡）、`/style profile`（规则表带置信度）

### 3.2 常用命令

| 命令 | 作用 |
|---|---|
| `/style status` | 开关 / 档案版本 / 规则数 |
| `/style card` | 当前风格卡原文 |
| `/style profile` | 规则表 |
| `/style undo` | 学歪了，回滚上一版 |
| `/style consolidate` | 规则攒多了，去重合并 |
| `/style reset confirm` | 清空（谨慎） |

### 3.3 两个坑，先说明白

- **它有个「交付门禁」只拦 `.docx / .pptx`**，对聊天没用，别指望它帮你拦聊天回复；它的价值在 `style_learn` 抽规则。
- **`style_analyze` 打分要指定 `genre: chat`**，否则用通用阈值，短句分数没意义。实测：真人短句 0 分，`综上所述，建议您优先考虑该方案…` 61 分。

## 4. 按心情改语气（桥接后自动生效）

虚幻每轮提示词里会多一段（心情来自 AstrBot 的 `bot_mood`）：

```
## 你现在的心情
happy（强度 0.61）——今天心情特别好，看什么都觉得很有趣呢~
说话时：更跳一点，多用「～」，表情多一个；别端着。
```

规则：
- **没心情数据就不写这段**（不编心情）
- 超过 48 小时的心情视为过期，不用
- 心情**只改语气**，不改「回不回」、不改事实
- 主人想换：`/set_mood serious` → 下一轮回复就收住

10 种心情各自的语气：

| 心情 | 说话变成什么样 |
|---|---|
| happy | 更跳，多用「～」，表情多一个，主动接话 |
| playful | 爱闹、爱接梗，敢逗人 |
| calm | 平稳，不多话，不硬撩 |
| curious | 多问一句，追着细节 |
| excited | 感叹号多，话多一点，语速快 |
| angry | 短、硬、少表情，不主动撩 |
| anxious | 小心，短句，少承诺 |
| sad | 话少、软，不闹 |
| nostalgic | 慢一点，爱提旧事 |
| serious | 不玩梗，直接答 |

## 5. 不灵了怎么查

| 症状 | 查这里 |
|---|---|
| 心情不出现 | `node -e "console.log(require('./src/learn').state())"` 看 `astrbot.mood` 有没有；AstrBot 是不是在跑（`http://127.0.0.1:6185` 能开） |
| 风格不出现 | `state().dsh` 有没有内容；`<工作区>/Writing-Style/` 有没有 `profiles.json` |
| AstrBot 学了但不进虚幻 | 审查队列没点通过；或插件被停 |
| 读不到数据库 | 报 `unable to open database file` 时桥会自动复制到临时目录再读；两次都失败就静默跳过（不影响回话） |

## 6. 删掉的东西

- `dsh-plugin-stylotrace@0.1.15`、`dsh-novel-craft@0.3.0` 已卸载：实测对 5~25 字短回复没用（stylotrace 短句恒定 85/100 分，只认书面套话），novel-craft 是小说工作台、零工具。
- AstrBot 的记忆类插件（memorix / mnemosyne / livingmemory / memshare）**没动**——那是记忆赛道，不是风格赛道。
