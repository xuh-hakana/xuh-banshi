## 2.5 ★星标与学话（她 2026-11-03 定，两套规则）

**星标 ＝ 学话最优先级数据。** 两个入口进同一个池 `src/data/chat-stars.json`：她在面板点 ☆ ＝ 她亲手认可（权重最高）；群里她的话被点表情回应 ＝ 群友认可（次高）。两者都代表「这次的回复被认可了」。

- 若注入星标 → 必须**带原句**，效果要能复现；不许只抽几条短句、更不许按句子长短删条目（删了就丢好内容）。排序：手动 > 点赞 > 有语境 > 短句。格式成对给：「对方「X」→ 她「Y」」。
- 免记录群（赛博鱼塘 143620228）：群友点赞不存；她手动星标照存（标 `fish`），学话时跳过。
- **学话学的是回复逻辑，不是口语化。** 9 项：该不该回 / 回的频率 / 一次回几句 / 是否用表情包 / 用词方向 / 是否比喻 / 是否接话 / 何时断话题 / 固定话术。不是句子长短、口头禅、标点这些表面。
- **key 只许一处**：`src/core.js` 的 `starsKey` ＝ md5(时间|昵称|文本)。面板、QQ 点赞全调它；各写一份就必然对不上号（2026-11-03 的三个 bug 都出在这）。
- 若黑名单群的人 → 不记好感；不是新功能、没有新开关：`noRecordGroups`（现只有赛博鱼塘 143620228）本来就是「什么都不记」，好感也归这道闸。判定只放 `config/index.js` 的 `isNoRecordGid()` 一处，别处不许另写。喜好表其余人按人物分、一节一人、好感高的在前。

## 3 ★表情包五池＋命名

位置 `xuhbot/src/data/stickers/`（`xuhuan mac/表情包` 是快捷方式，她在那里管图）

- 五池（权重）：`常用/`+`虚幻/`→main(48)｜`可用/`→usable(6)｜`关键词触发/`→kw(8，命中即发不抽签)｜`少用/`+根目录 q 名图→normal(1)。**只 kw + 少用 里 q 名图算 500 上限**，满了私聊提醒。
- 若收图 → 落点只有 `少用/`；根目录不再承担收发（2026-11-03 她定）。她发的情绪图才进 `可用/`，别人发的全收，单张上限 8MB，无每日上限。
- 若命名 → 情绪类 `q<情绪><序号>`（`q哭1`）；内容类 `<描述><序号>`（`蓝发小女孩2`）。**总长 ≤10 字**，超了被洗名截断。调取可省编号：`[表情:q哭]` 在 `q哭1`/`q哭2` 间随机挑。
- `-` 安全（`stickerName()` 只删 `\ / : * ? " < > |` 和中文标点，不删 `-`）。
- 若动 `常用/` → 别乱往里放图；她手挑那批（17 张，已补场合）动一张先问。
- 若她在对话里发情绪图 → 按规则存对应池，并在 `常用.md` 补一行场合。
- 与「QQ 机器人自动收集群表情」同一套通道（已合并），不分两套。
