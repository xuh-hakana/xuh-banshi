## 〇、分类体系（v3 定稿）

| 类 | 名称 | 判据 |
|---|---|---|
| **A** | QQ 群专属 | 仅群内、带 `!isPrivate`/群键；"QQ 群的专属也要独立" |
| **H** | 全聊天场景 | 所有"聊天"形态都生效（QQ群 + QQ私聊 + B站私信），相对"公开发评论"；**原 C 聊天层、原 G 全平台私聊、原 H 全聊天全部合并为此类** |
| **B** | 测试专属 | 全场景测试总集合汇报 + 报错总集合汇报（日记测试、表情包报错等） |
| **D** | 平台功能专属 | 单平台单功能；D1=QQ空间、D2=B站（分私信/评论区）、D3=直播陪玩 |
| **E** | 特殊通用 | 跨多平台、非即时回话（日记规则本体） |
| **F** | 全场景通用 | 全排除后剩下；**分场景选择注入（不全量）、文件按类分开（不合并大文件）** |
| **I** | 独立 | 身份层 `masterQQ`/`masters`/`oniiQQ`，不塞任何类 |
| **X** | 逻辑 X | 采集逻辑、非回话规则 |

- **聊天类**（H 全聊天、A 群专属）←→ **公开发评论类**（D 的空间/评论区）
