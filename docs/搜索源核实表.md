# 搜索源核实表（2026-11-22）

核实方法：逐条打开官网/官方文档原文（不是二手博客），页面打不开或仓库 404 的标 ⛔；额度数字一律抄官网原句。
本机实测：`node scripts/websearch-probe.js`。代码里的同一份数据在 `src/websearch.js` 的 `PROVIDERS`。

## 结论速览

| 说法 | 核实 | 真实情况 |
|---|---|---|
| Tavily 1,000 次/月 | ✅ | 1,000 credits/月，basic 搜索 1 credit/次（advanced 2） |
| Serper 2,500 次/月 | ❌ | 注册一次性 2,500 次，**不按月重置** |
| Exa 1,000 次/月 | ❌ | 每月 $10 信用额度（每月 1 号重置），≈2,500 次 Lite 搜索 |
| WebSearchAPI 2,000 次/月 | ✅ | Free 档 2,000 search credits/月 |
| You.com 100 次/日免注册 | ⚠️ | 额度属实，但**只走 MCP 通道**，没有免 Key 的 REST |
| Openperplex 500 次/月 | ⛔ | 官网已停放、GitHub 组织 404，无法核实 |
| DuckDuckGo 免 Key 搜网页 | ❌ | Instant Answer 只给摘要/话题，不是网页结果 |
| AnySearch 匿名额度 | ✅ | 匿名 1,000 次/日、10 QPS，按 IP 限流；POST /v1/search |
| Firecrawl /v2/search 免 Key | ❌ | 必须 API Key；免费档 1,000 credits/月（≈500 次搜索） |
| Marginalia 无密钥端点 | ⚠️ | 要 `API-Key` 头，公共 key「public」实测 429 |
| SearXNG 自托管免费 | ✅ | 无 Key 不限量，但 `settings.yml` 的 `formats` 必须加 `json` |
| CRW / InfoMesh | ✅ | 真实存在，但都是**本地进程/MCP**，不是 REST |

## ② 零配置免 Key

| 源 | 实质 | 本机结果 | 出处 |
|---|---|---|---|
| AnySearch | 匿名 1,000 次/日，POST https://api.anysearch.com/v1/search | ✅ 200，有结果 | https://www.anysearch.com/docs/auth |
| Marginalia | 要 `API-Key`，公共 key=`public` | ❌ 429 QPM Limit Exceeded | https://about.marginalia-search.com/article/api/ |
| DuckDuckGo | Instant Answer 只有摘要；网页端点需抓页（红线） | 不接 | https://duckduckgo.com/api |
| Firecrawl | /v2/search 要 Key；免费 1,000 credits/月 | 不接 | https://www.firecrawl.dev/pricing |

## ③ 自托管（完全免费，但要自己跑）

| 源 | 说明 | 注意 |
|---|---|---|
| SearXNG | 聚合 40+ 引擎，无 Key | `settings.yml` → `search.formats: [html, json]`，否则 `?format=json` 403；内存「约 200MB」未实测 |
| CRW (fastcrw/crw) | 本地 Rust 二进制，免账号；Firecrawl 兼容 /search | 是本地进程/MCP，不是 HTTP 服务 |
| InfoMesh | P2P，永久免费 | 仅 Python MCP 包（pip install infomesh），要跑节点 |

## 本轮实际接入

- AnySearch（匿名，默认开，`webSearch.anysearch=false` 可关）：链路第四位，前三家全空才跑。
- SearXNG：原有 `searxUrl` 不变，补了 403 提示。
- 其余一律只登记不调用：要 Key 的全在红线外（0 元原则），需自跑的等主人决定是否部署。
