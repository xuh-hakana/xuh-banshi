## 2. 心情值到底由什么决定

**① 起始是随机的。**
- 类型：`random.choice(10 种)`
- 强度：`random.uniform(0.3, 0.9)`
- 描述：每个类型 3 条模板里随机挑一句

**② 之后被真实事件修正。**
- 被夸 / 被鼓励 → `happy`，持续 4 小时
- 收到礼物 → `excited`
- 被骂 / 侮辱 → `sad` 或 `angry`，持续 2 小时
- 被骚扰 / 威胁 → `anxious`
- 强度来自交互规则里的 `mood_effect`（普通聊天 0.1、称赞 0.2、夸赞 0.3…），描述还是模板随机挑

**③ 心情和好感互相影响。**
- 心情修正好感：happy ×1.2、excited ×1.3、playful ×1.1
- 好的心情下善意调侃才加分，差心情会拒绝（日志里那句「当前心情(anxious)不适合善意调侃」就是这里）

**④ 「每天 6 点换心情」没有实现。**
`_daily_mood_updater` 到点只写了 `pass`。实际节奏是：**启动时随机一次 → 24 小时过期 → 下一次交互时重新随机**。

## 3. 三个坑

1. **AstrBot 的心情提示词只作用于 AstrBot 自己的回话**。QQ 聊天是 xuhbot 在回，所以以前这条完全不起作用；现在靠桥读 `bot_mood` 才进虚幻的提示词。
2. **DSH 两个风格插件吃的是长文样本/改稿**，不是群聊短句。对 5~25 字的聊天，能用的只有「档案里的规则」，不是「风格本身」。
3. **情绪书判的是别人的情绪，不是她自己的心情**。混了会变成「对方难过 → 她也难过」，人设里不是这么写的。
