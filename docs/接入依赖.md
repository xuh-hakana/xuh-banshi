# 怎么把依赖接上

这份只讲一件事：让三个工具跑起来还差什么、每一件怎么装、装完在哪填、怎么确认接好了。
装一样验一样，别一次全上；出问题先看最后一节的报错表。

| 依赖 | 必需？ | 不装会怎样 |
|---|---|---|
| Node.js ≥ 22 | 必需 | 客户端和机器人都起不来 |
| NapCat（QQ 协议端） | 必需 | 收不到群里任何消息 |
| 模型 Key | 半必需 | 三个工具照跑，机器人不会说话 |
| Python 3 + Pillow | 可选 | 图判级退化成粗略规则，误判变多 |
| ffmpeg | 可选 | 视频不抽帧，只认封面 |
| whisper 模型 | 可选 | 语音不转文字 |

---

## 一、Node.js ≥ 22

**它管什么**：跑机器人（`src/bot.js`）和桌面客户端（`client/`）。低于 22 会因为语法和一些 API 直接报错。

**装**：

```bash
# macOS（有 Homebrew）
brew install node
# Windows：去 https://nodejs.org 下 LTS，一路下一步
# Linux
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
```

**确认**：`node -v` 要打出 `v22` 或更大。装完重开一个终端再验，PATH 才刷新。

---

## 二、NapCat（QQ 协议端）

**它管什么**：它是真正连 QQ 的那个程序，本项目通过它收发消息。没有它，三个工具都没数据。

**装**：

1. 从 https://github.com/NapNeko/NapCatQQ/releases 下载对应系统的包
2. 解压后启动（Windows 双击 exe，macOS 运行包里的启动脚本）
3. 扫码登录你要用的那个 QQ 号
4. 在 NapCat 里打开 **HTTP 服务**（默认端口 3000）和 **WebSocket 服务**，记下 token（如果你设了）

**在本项目哪里填**：`.env` 里这几行——

```ini
QQ_ACCOUNT=你的QQ号
NAPCAT_HTTP=http://127.0.0.1:3000
NAPCAT_TOKEN=你在NapCat里设的token
```

**确认**：`npm start` 起来后，群里随便发条消息，控制台应该出现收到消息的日志。
**注意**：必须和本程序在**同一台机器**上跑，远程连不上是正常的。

---

## 三、模型 Key

**它管什么**：机器人说话、图片自动描述、情绪判断。三个工具本身（搬屎去重、图入库、判级）是本地逻辑，不给 Key 也能跑。

**装**：去你选的提供方后台拿一个 Key（DeepSeek / OpenAI 等兼容 OpenAI 协议的都行）。

**在本项目哪里填**：`.env`——

```ini
LLM_BASE=https://api.deepseek.com
LLM_KEY=sk-你的key
LLM_MODEL=deepseek-chat
```

**确认**：`npm start` 后群里 @ 机器人说句话，有回复就通了。
**省钱的开关**：不想让模型看每张图，就去客户端「开关」页把「自动写表情包描述」关掉。

---

## 四、Python 3 + Pillow（可选，判级更准）

**它管什么**：图片判级用 Pillow 读像素特征，比纯规则准。没有它程序会自动退回规则版，不会崩。

**装**：

```bash
python3 -m pip install --upgrade pip
python3 -m pip install pillow
```

**确认**：`python3 -c "import PIL; print(PIL.__version__)"` 打出 10.x 之类就成。

---

## 五、ffmpeg（可选，视频抽帧）

**它管什么**：群里发的视频会抽几帧当图判断，不装就只看封面。

**装**：

```bash
brew install ffmpeg          # macOS
sudo apt install -y ffmpeg   # Linux
winget install Gyan.FFmpeg   # Windows
```

**确认**：`ffmpeg -version` 有输出。

---

## 六、whisper 语音模型（可选，1.5 G）

**它管什么**：群里的语音转成文字。不用语音功能就别下，白占 1.5 G。

**装**：

```bash
mkdir -p src/data/models
# 下载 ggml-large-v3-turbo.bin 放进上面这个目录
```

模型地址：https://huggingface.co/ggerganov/whisper.cpp（选 `ggml-large-v3-turbo.bin`）。

**确认**：文件在 `src/data/models/ggml-large-v3-turbo.bin`，发条语音试试有没有回复。

---

## 七、客户端（桌面壳）

**它管什么**：表情包页（含情绪书）、搬屎页、右下角 ⚙ 参数浮层。不装它，三个工具照样在后台跑，只是没法看和改。

**装**：双击 `client/启动.command`（macOS/Linux）或 `client/启动客户端.bat`（Windows）。
第一次会自动装 Electron，只装一次。

**确认**：窗口打开，左栏「表情包 / 搬屎」两个入口能点，右下角 ⚙ 能打开参数浮层；
浮层里改一项，`config/features.json` 里的值跟着变。

**换肤 / 夜雨玻璃**：左上角「换左上角图」换图，「调头图位置」调位置；右上角「夜」切夜晚（雨滴玻璃），默认按钟点自动（06:00–17:59 白天）。

## 八、Windows 怎么开

两条路，任选一条。

**路 A：源码版（推荐，最省事）**

1. 装 Node ≥ 22（https://nodejs.org 下 LTS）
2. 双击 `client\启动客户端.bat`
3. 第一次会自动装 Electron（约 100 MB，几分钟），装完窗口自己开

**路 B：打包好的 exe 版**

1. 解开 `xuhbot-win-0.3.0.zip`，进 `xuhbot-win32-x64`
2. 把仓库里的 `src\`、`config\`、`public\`、`package.json`、`.env` 复制到本目录的 `resources\` 下（和 `app` 文件夹同级）
3. 双击 `xuhbot.exe`

exe 只是界面壳；机器人本体还是 Node 程序，仍然在项目根用 `npm start` 跑（或者用 `启动机器人.bat`）。
自己打一份 exe：`npm run pack:win`（需要联网下载 win32 版 Electron）。

**Windows 上常见的三个坑**

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 双击 bat 一闪就没 | 没装 Node，或装了但没重开资源管理器 | 装 Node ≥ 22，注销/重启后重试；或在 cmd 里手动跑 bat 看报错 |
| 窗口开了但「开关」页读不到配置 | 解压路径带中文/空格，或不在项目目录里 | 整个仓库放到纯英文路径（如 `D:\xuhbot`）再开 |
| exe 打开一片白 | `resources` 里没放 `src\`、`config\` | 按路 B 第 2 步补齐，或设环境变量 `XUHBOT_ROOT` 指向仓库根 |

## 报错怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `node: command not found` | 没装 Node 或没重开终端 | 装 Node ≥ 22，关掉终端重开 |
| 客户端一直停在「正在读配置」 | 没生成 `config/features.json` | 在项目根跑 `npm run init` |
| 群里没反应 | NapCat 没登录 / 端口或 token 不对 | 先在 NapCat 里看登录状态，再核对 `.env` |
| 机器人不回话 | Key 不对或余额没了 | 填 `LLM_KEY` 后重启，看日志里有没有 401 |
| 判级明显不准 | 没装 Pillow | 按第四节装，重启程序 |
| 表情包页空白 | `stickerDir` 指向的目录不存在 | 客户端「开关」页把路径改回来，或跑 `npm run init` |
| 搬屎不动 | 总开关关着 / 群号没填 | 「开关」页打开总开关、填源群和目标群 |

本手册对不上时，先看 `client/日志/客户端.log` 和项目根 `日志/` 下最新的那个。
