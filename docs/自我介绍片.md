## 这条片子怎么来的
1. **风格样本分级**（`src/mediagen/style-source.js`）：主人在 B 站发的动态 > 主人给的 5 条例句（`src/data/master-examples.json`，学机制不抄句子）> 人设五件套。
2. **多重真相**（`src/mediagen/audience.js`）：用 `persona.rolePrompt('groupmate')` 分别扮演宅男／普通上班族／程序员／青少年，各自说出「日常／想要什么／期待虚幻给什么／会划走什么」，记录员按 multi-truth 格式落盘 `src/data/multi-truth/out/bili-selfintro.json`，文案侧用同目录读回。
3. **文案**（`src/mediagen/copy.js`）：YouTuber 五段（hook→我是谁→我做什么→为什么关注→CTA），提示词里写死人设语感（短句、句末不加句号、笑只用「嘻嘻」、哭用「呜」、禁括号旁白、禁自证不是机器人、必须有幽默+撩+情绪）+ 字数硬指标 205-245 字；门禁不过退回重写，两次不过直接报错，不静默出片。
4. **配音**（`src/mediagen/tts.js`）：edge-tts `zh-CN-XiaoyiNeural`（Cartoon/Lively），语速 -6%，每句单独出 wav + SRT 词级时间轴。
5. **形象**（`src/mediagen/liveframe.py`）：5 张贴纸直出 1080p 帧——白底自动抠图、圆角小卡、投影、呼吸缩放、待机摆动、说话时下颌轻抬（跟每句 wav 的 RMS 走）、眨眼（眼部条带压扁）。
6. **合成**：PIL 帧流直接喂 ffmpeg rawvideo（本机 ffmpeg 无 drawtext，字幕是 PIL 画的 PNG 气泡），BGM 走 `src/mediagen/music.js` 程序化编曲，人声 1.0 / BGM 0.16。
7. **投稿预演**：只写参数并校验（标题 ≤80、简介 ≤2000、标签 ≤10、分区 188），`real:false`。

## 必须知道的三条边界
- **不是真 Live2D**：5 张 jpg 没有分层 PSD，反推不了部件绑定。交付的是「Live2D 风格 2.5D 动态立绘」。要真 Live2D 得给分层 PSD/PSD 导出。
- **这次 B 站动态没拉到**（`tier1=0`，B 站风控）：样本降级到「主人例句 5 条 + 人设」，`sources.json` 已记录；间隔一会儿重跑能再取到（上一次跑拿到了 3 条）。
- **四类观众画像是推断的**：web_search 只有标题没正文，B 站 opus 页面被验证码挡了，`persona.json` 里标了 `inferred`。要更准就补真实弹幕/评论样本。
