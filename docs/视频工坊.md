# 视频工坊（一句话 → 成片 → B 站）

一句话进，出成片，能投到 B 站。**核心思路：不自研剪辑/字幕/投稿，分场景下载成熟的轮子，只写一层薄编排。**

## 分场景用了什么

| 场景 | 轮子 | 怎么用 | 需不需要额外 key |
|---|---|---|---|
| 一句话成片（配音+字幕+剪辑+合成） | MoneyPrinterTurbo（145k★） | `mpt cli`，装在 `data/vendor/mpt-venv` | 不用（Edge TTS 免费） |
| AI 画面 | 智谱 CogVideoX-Flash / CogView-3-Flash | `src/mediagen/clips.js` 直连 API | 用已有的 zhipu key |
| 配乐 | 程序化编曲（纯 Node 合成 wav） | `src/mediagen/music.js` | 不用 |
| 文案/分镜 | deepseek / 智谱 | `src/mediagen/llm.js` | 用已有 key |
| B 站投稿 | biliup（Rust，5.6k★） | `src/mediagen/bili.js` 包一层 | 复用现有 B 站登录态 |

## 装

```bash
node scripts/setup-video.js          # 装 uv + python3.11 venv + mpt + biliup（幂等）
node scripts/setup-video.js --check  # 只查状态
```

装完三件套：
- `data/vendor/mpt-venv` —— MoneyPrinterTurbo（Python 3.11 venv）
- `data/vendor/biliup/biliupR-v1.3.5-aarch64-macos/biliup`
- `data/vendor/uv`、`data/vendor/pythons`

> 为什么用 uv 不用 brew：本机 `/opt/homebrew` 归另一个用户所有，`brew install` 直接 Permission denied。
> uv 把 Python 装进工作区，不动系统目录。

## 跑

```bash
# 实跑一条（调视频模型，约 5-12 分钟）
node scripts/video-factory.js --topic "AI视频到底是怎么生成的" --live

# 只出图不出视频（最快，约 2-3 分钟）
node scripts/video-factory.js --topic "..." --shots 3

# 用自己写的文案
node scripts/video-factory.js --topic "..." --script "第一句。第二句。" --live

# 断点续跑（每个作业都有 state.json）
node scripts/video-factory.js --resume 20261125-060102

# 投稿演练（默认，不真发）
node scripts/video-factory.js --topic "..." --live --publish

# 真投稿
node scripts/video-factory.js --topic "..." --live --publish --publish-real
```

产物落 `data/videojobs/<jobId>/`：`plan.json` / `clips/` / `bgm.wav` / `out/final.mp4` / `state.json`。

## 降级链（每一层都有退路）

1. **视频模型排不上队/限额** → 该镜头自动退成「文生图 + 缓慢推拉」，成片照出。
2. **LLM 挂了** → 用模板文案，不生硬断。
3. **配乐** → 程序化编曲，零成本必成功；哪天有 Mureka/Suno 兼容 key，改 `src/config/media.json` 的 `music.provider` 即可。
4. **投稿** → 默认只演练；真发要显式 `--publish-real`。

## 配置

`src/config/media.json`：LLM 源/模型、TTS 音色、分镜数、分辨率、投稿默认分区与标签、`dryRunDefault`。
key 全部来自 `src/mediagen/keys.js` → 读 AstrBot 的 `~/.astrbot/data/cmd_config.json`，不落盘、不打印。

## 已知边界

- MPT 的 BGM 只认自定义文件，所以配乐是我们合成好再喂进去。
- B 站新人账号首次投稿可能触发风控（审核/短信验证）；`--publish-real` 前先自己确认。
- 目前没有「音乐大模型」key：MiniMax 音乐 API 已对新用户关闭（HTTP 410），SiliconFlow 余额不足。
- 克隆音色（fish-speech / CosyVoice）留了位置没接，需要再装模型。
