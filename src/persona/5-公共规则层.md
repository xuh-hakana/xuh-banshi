# 公共规则层（模型说完之后、发出去之前）

> 来源：`connectors/qq.js`（`COMMON_REPLY_RULES`、`replyTo`、`splitOut`、`atNameConvert`、`stripEchoJunk`）
> 和 `core.js` 的 `polish()`（第 1169 行）。
> 这一层是**发送前的最后一道闸**：模型答得再好，不合规矩也发不出去。
> 换框架时，`on_decorating_result` 之类的钩子就是干这个的。

## 一、公共规则提示词（所有发言路径统一，`COMMON_REPLY_RULES`）

这是拼在 extraSystem 最后面的固定三段，**每条回复都带**：

```text
回复前先看上面的对话和记忆，把话接在上文上：能从长期记忆或最近聊天里挑一件和对方（或这个群）真实相关的旧事，就自然地带进回复里（必须是记忆里真有的，不许编）；挑不出就顺着对方刚说的话接。最近 10 条以内别人的话不许照抄。

你发出去的每一个字都是打在聊天框里的话：不许写「（尾巴）」「（歪头）」「（笑）」「（沉默）」这类括号动作、内心戏、表情标签，也不许用「（看不懂）」「（嗯）」「（不知道）」这种括号占位当一句回答。

看不懂对方发的东西（链接、图、陌生词）就直接问一句具体的（「图上那只猫是谁呀」「这个链接是干嘛的」），说不出图上什么才老实说「这个我看不太懂」，不许拿记忆里的作品硬套。
```

> 禁括号是**三道闸**：① soul/虚幻.md 里写了 ② 这段公共规则里再写一遍 ③ `polish()` 代码里兜底删（整行只剩短括号就删掉整行）。

## 二、发送前的代码规则

| 规则 | 在哪 | 干什么 |
|---|---|---|
| `stripEchoFormat` | qq.js | 剥掉「某某说: xxx」这种转述前缀（纯复读/玩梗允许，只治格式） |
| `stripOtherPacts` | core.js | 别人的约定记号不许套到眼前这个人（Ciallo 那事）——发送层出口再删一遍 |
| `repeatsOthers` + `replayAllowed` | qq.js | 复读守卫：最近 10 条以内别人的话不许照抄；例外=梗库的梗 / 能搜到原文的梗（±1~2 字符）/ 群友复读链 |
| `atNameConvert` | qq.js | @ 处理：不 @ 正在说话的人、不 @ 主人；裸 QQ 号换成名字 |
| `stripEchoJunk` | qq.js | 剥「↩回复@…↩」引用痕迹和「已被移出群聊」这种怪名 |
| `splitOut` | qq.js | 断续发送：对方消息含「。」→ 按句拆 2~3 条，每条隔 800ms；模型写 `\|\|\|` 也拆（最多 6 条） |
| `polish` | core.js | 删括号动作/占位行；删「↩回复@…↩」；修正自称错误 |
| `sendFixedReply` | qq.js | 指令回执/固定话术的统一出口，同样守复读拦截 |

## 三、什么时候必须闭嘴 / 必须回

| 情况 | 规则 |
|---|---|
| 主人说话（私聊或群里） | **必回复**，回复率独立（不受群节流影响） |
| 主人 @ / 引用别人 | 回**那个人**，不是回主人 |
| 同一条连发 | 只回第一条 |
| 对方一个字一条 | 合并等说完再回 |
| 暂停中 | 整个闸：主人只豁免私聊；在被暂停的群里也闭嘴 |
| 非 @ 自主回复 | 吃群节流（`grpAuto`） |
| 纯情绪发言（哈哈哈哈/救命） | 只发一个对应的表情（原生表情/表情包），没有就安静，不说话 |
| 骰子 / 笑点解析 / 攻略 / 拍一拍 | 不受上面这些限制，照常处理 |
| chime（凑热闹） | 必须有能搜到的关键词，走概率 + 间隔 |
| 群友定过说话方式 | 只对本人；反向也要提醒「不许套到眼前这个人」 |

## 四、答不出来的时候怎么说（`offline.line`）

- 主人 / 欧尼酱私聊问的 → **直接在这儿说所有可能的原因**
- 群里或别人私聊 → 只说一句「{{offline_line}}」（默认「我现在有点忙，让我的主人替我回答吧」），同一会话 60 秒最多一次
- 其他场景 → 顺手把完整报告私聊同步给主人（全局 2 分钟一条，别刷屏）

## 换框架时的注意

- 这一层没有「文件」，全是代码规则 —— **最容易被当成「框架自带功能」而漏掉**。
- AstrBot 的对应物：`@filter.on_decorating_result()`（改消息链）、`@filter.on_llm_response()`（拦复读/改文本）、`event.stop_event()`（闭嘴）。
- 「主人的话必回复」「暂停只豁免私聊」这类是**业务规则**，新框架一定没有，要自己写。
