## 四、防再变乱的机制（2026-11-01 加）

以前是压缩一次、过几个月又散。现在改成三道闸，不靠我自觉：

| 闸 | 什么时候启动 | 干什么 |
|---|---|---|
| 写前查 | 每次要新增一条规则 | 先搜现有文件有没有；有就改旧的，同类就并进去，不许新增平行条目 |
| 单一归属 | 定这条放哪时 | 一条规则只有一个家，别处只写「见 X」，不重述 |
| 跑脚本 | 每次改完记忆 | 跨文件找出重复句，报告里出现同一句两处，当场合并 |

**`检查冗余.py`**（在 `~/.workbuddy/user-…-personal/`）：就是上面第三道闸的检查器。纯本地 Python，不联网、不调模型、不耗积分，一万字规模 1 秒跑完。你自己想查也能跑：

```bash
python3 "/Users/zhengbowen/.workbuddy/user-4641772a-9652-455b-9085-ab314b5df106-personal/检查冗余.py"
```

**一条判据（取代原来的字数上限）**：该放常驻还是按需，看**漏读会不会犯具体错**，不看用得多不多；该不该拆，看**是不是被分开读**，不看长短。原来那个「常驻 >1600 字、按需 >4000 字」的硬指标已作废。
